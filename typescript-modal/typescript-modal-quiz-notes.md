## Quiz Questions

Answer the following questions in the provided markdown file before turning in this exercise:

- What is the `<dialog>` element used for?
  // The <dialog> element in HTML is a native web component used to create pop-up dialogs or modal windows on a webpage.

- How do you display a modal dialog?
  // show()

- How do you hide a modal dialog?
  // close()

- What is the difference between the `showModal` & `show` methods?
  // The showModal() method displays a <dialog> element as a modal, preventing interaction with other content on the page until the dialog is closed. The show() method displays the <dialog> element but allows interaction with other page content.
